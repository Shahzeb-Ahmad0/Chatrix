#Chatrix 💬

Chatrix is a modern real-time chat web application built using the MERN Stack and Socket.IO. It enables users to communicate instantly with real-time messaging, online user status, profile customization, and image sharing in a clean, responsive interface.

🚀 Features
🔐 User Authentication (Register/Login)
💬 Real-time one-to-one messaging using Socket.IO
🟢 Online/Offline user status
👀 Seen message support
🖼️ Profile picture upload using Cloudinary
✏️ Update profile and bio
📩 Unread message counter
📱 Fully responsive design (Desktop, Tablet & Mobile)
⚡ Fast React + Vite frontend
🌙 Modern dark-themed UI
🛠️ Tech Stack
